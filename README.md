# ESP32 Bluetooth Gear Indicator

This project is a DIY wireless gear indicator designed for sim racing enthusiasts. It uses an ESP32-WROOM-32 microcontroller and a 1.8-inch ST7735 TFT display to show real-time gear information received from a racing simulator through Bluetooth.

The project focuses on creating a compact, standalone display that can be integrated into a custom sim racing setup.

### Features
- ESP32-based Bluetooth communication.
- 1.8-inch ST7735 TFT color display.
- Real-time gear display.
- Animated sports car and waiting animation.
- Bluetooth connection status indicator.
- Custom firmware developed for the project.
- Compact and customizable hardware design.

### Repository Contents
This repository includes the complete project resources:

- Detailed wiring diagrams and pin connections.
- Hardware components and specifications.
- Step-by-step construction and assembly guide.
- Complete ESP32 firmware.
- Arduino IDE setup and library requirements.
- Bluetooth configuration and SimHub integration instructions.
- Troubleshooting information.

### Hardware Requirements
- ESP32-WROOM-32
- 1.8-inch ST7735 TFT Display (128×160)
- Li-ion battery
- Battery charging and power module
- Connecting wires and other assembly materials.

### Purpose
The goal of this project is to provide an affordable and customizable Bluetooth gear indicator for sim racing setups, with all the necessary information available to build, modify, and improve the device.

Feel free to explore the repository, build your own gear indicator, and customize it according to your requirements.
